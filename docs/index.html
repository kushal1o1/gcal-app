How it works

  1. Tap the mic and say what you need, for example "remind me in 2 hours 30 minutes to leave".
  2. Check the preview. It shows the time and whether the reminder is urgent or repeats.
  3. Create it. The event goes into your Google Calendar, and Google sends the alert.

Install

  • Download the APK that matches your phone.
  • Open it and allow installs from your browser when Android asks.
  • Open gcal, go to Settings, and enter the server address and token.

Your own server

gcal needs a server to turn your words into calendar events. The server code is open source, and you can run your own copy. See the server README.
